# 普通聊天文档处理规划

目标：让用户上传文档后，通过聊天理解内容、预览变更、生成可下载的新版本；原格式编辑与跨格式转换分别处理。

## 第一阶段：XMind 转 PPT（当前实现）

- 聊天支持上传 `.xmind`，在所属会话中保存原始文件和解析后的结构；附件可重新打开、下载原件并查看拆页。
- 支持现代 JSON 和旧版 XML 内容；多工作表、主题层级和纯文本备注可转换。
- 按中心主题、一级主题拆页，较长内容分页，生成可编辑的 PPT 文本和演讲者备注。
- 当前支持全局策划和分批内容设计；可解析的关联线端点作为文字参与策划。PNG/JPEG 主题图片可与简短正文同页，内容较多时放在附近的独立页。启用看图时，最多将前 10 张交给当前模型观察并参与规划。安装并启用 WPS 加载项后，可后台渲染实际页面，逐页视觉审阅并尝试调整文字页布局，再渲染复查一轮；结果明确报告未检查、检查中断或残留问题。原始布局、关系线形状、附件和标记尚未还原。未保存原件的旧版附件需重新上传才能提取图片。

## 后续阶段

1. 在现有原件存储和会话隔离基础上，增加衍生文件的持久存储、版本链和清理策略。
2. 引入格式无关的结构化文档模型与带稳定 ID 的读取、搜索、修改操作，支持预览和回退。
3. 扩展现有 XMind/PPT 读取与生成工具，加入更多文档格式、视觉预览及可追溯的结构化编辑。
4. 分别接入 Word、PPT、XMind 解析与原格式编辑；复杂元素不支持时明确列出。
5. 为 PDF 区分文本、扫描件和表单；逐页渲染和 OCR，先支持提取与新文档生成，再扩展原位编辑。
6. 接入格式转换队列、进度和取消；导出后执行渲染、文本覆盖和版式检查，提供可视预览与下载。
7. 通过真实样本和跨平台打包测试验证格式保真、可编辑性、文件安全及长文性能。

## 普通聊天原生工具（P0 / P1）

- 普通聊天通过 OpenAI 兼容工具调用处理文档，不再依赖关键词切换到创作助手；不支持工具调用的渠道会给出提示并降级到纯聊天。
- 支持创建、读取、列出和请求删除 TXT、Markdown、CSV、JSON、XMind 文件，以及 XMind 转 PPT；文本格式还支持搜索及精确修改，删除需要用户在工具卡上确认。
- 新生成文件位于应用数据目录下的会话工作区，保留旧数据库附件与文件下载兼容性。删除会话会清理其工作区。
- 限制：不支持 Word、Excel、PDF 和 PPT 原文档的读写；WPS 渲染需要本机 WPS 及启用加载项，视觉审阅需要启用看图且当前模型支持视觉；自动修正目前限于文字页面布局。
